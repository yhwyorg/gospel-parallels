# Gospel Parallels — yhwy.org

To the glory of God, and for Darrell W. Johnson.

Read Matthew, Mark, Luke and John side by side. Pick a section or type any
passage (`Luke 15:11-32`, `Jn 3:16`) to see every account of it in parallel
columns, with the sections before and after it in each Gospel. The Order page
lines up two Gospels and shows where they tell events in a different order.

## Run it

```sh
npm install
npm run dev      # http://localhost:5173
npm test         # data and parser checks
npm run build    # static site in dist/
```

## How it fits together

| File | What it is |
| --- | --- |
| `src/data/sections.ts` | The Gospels divided into sections, with parallels and notes. **Edit this to change the sections.** |
| `src/data/gospels.json` | World English Bible text of the four Gospels, generated by `scripts/build-gospel-text.mjs`. |
| `src/lib/refs.ts` | Reference parsing (`8:31-9:1`, `Mk 4:35`). |
| `src/lib/corpus.ts` | Indexes sections against the text; derives each Gospel's order from where its verses fall. |
| `src/lib/sequence.ts` | Works out which sections two Gospels tell in a different order. |
| `src/views/` | The pages. |

Each Gospel's order is never typed in by hand; it comes from the verse
references. `npm test` fails if any verse of any Gospel is in no section or in
two, or if a reference points at a verse that doesn't exist.

## Text

World English Bible (public domain), from
<https://ebible.org/find/details.php?id=engwebp>. To regenerate:

```sh
curl -L -o engwebp_vpl.zip https://eBible.org/Scriptures/engwebp_vpl.zip
unzip engwebp_vpl.zip -d engwebp_vpl
node scripts/build-gospel-text.mjs engwebp_vpl/engwebp_vpl.txt
```

## Hosting

GitHub Pages, deployed by `.github/workflows/deploy.yml` on every push to
`main` (tests must pass first). `public/CNAME` sets the custom domain. DNS for
yhwy.org lives at Namecheap: four `A` records on `@` pointing at GitHub Pages
and a `CNAME` for `www`.

## History
