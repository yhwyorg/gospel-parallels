# Gospel Parallels — gospels.yhwh.rest

Soli Deo gloria. Made for Darrell W. Johnson.

Read Matthew, Mark, Luke and John side by side. Pick a section or type any
passage (`Luke 15:11-32`, `Jn 3:16`) to see every account of it in parallel
columns, with the sections before and after it in each Gospel. The Order page
lines up two Gospels and shows where they tell events in a different order. The
Timeline sets every section in harmony order with a row per Gospel, marking the
periods of the ministry and the days of the last week, and dashing any block a
Gospel tells at a different point. The Book page has every section in one volume,
to print or download as a PDF.

The site is in eleven languages, each with a published translation of its own
(below). It opens in the language the reader's browser asks for, and the menu in
the header switches it; `?lang=es` in the address picks one directly.

## Run it

```sh
npm install
npm run dev      # http://localhost:5173
npm test         # data and parser checks
npm run build    # static site in dist/
npm run books    # PDFs of the Book page into dist/book/ (after build)
BOOK_LOCALES=en npm run books   # just one language
```

`npm run books` checks each PDF before writing it: all 220 sections and every
verse present, and every glyph drawn in a font the stylesheet names (on Linux,
install `fonts-noto-core fonts-noto-cjk`, as the deploy workflow does).

## How it fits together

| File | What it is |
| --- | --- |
| `src/data/sections.ts` | The Gospels divided into sections, with parallels and notes. **Edit this to change the sections.** |
| `src/data/text/<locale>.json` | Each language's Bible text of the four Gospels, generated by `scripts/build-gospel-text.mjs`. |
| `src/i18n/dict/<locale>.tsx` | Everything the site says in each language, including section titles and notes. `en.tsx` is the source; `src/i18n/dict.ts` documents each entry. |
| `src/i18n/books.ts` | Gospel names in every language; the lookup box accepts any of them. |
| `src/i18n/locales.ts` | The languages, their translations and licences, and how the language is chosen. |
| `src/lib/refs.ts` | Reference parsing (`8:31-9:1`, `Mk 4:35`). |
| `src/lib/corpus.ts` | Indexes sections against the text; derives each Gospel's order from where its verses fall. |
| `src/lib/sequence.ts` | Works out which sections two Gospels tell in a different order. |
| `src/data/timeline.ts` | The timeline's periods, and the days of the last week where the Gospels mark them. |
| `src/lib/timeline.ts` | Lays the harmony out as timeline columns and finds what each Gospel tells out of order. |
| `src/views/` | The pages. |

Each Gospel's order is never typed in by hand; it comes from the verse
references. `npm test` fails if any verse of any Gospel is in no section or in
two, or if a reference points at a verse that doesn't exist.

## Text

Every text comes from eBible.org and is used unchanged:

| Language | Translation | Licence |
| --- | --- | --- |
| English | World English Bible (`engwebp`) | Public domain |
| Español | Reina-Valera 1909 (`spaRV1909`) | Public domain |
| Français | Louis Segond 1910 (`fraLSG`) | Public domain |
| Português | Bíblia Portuguesa Mundial (`porbrbsl`) | Public domain |
| Deutsch | Lutherbibel 1912 (`deu1912`) | Public domain |
| Русский | Синодальный перевод (`russyn`) | Public domain |
| العربية | Van Dyck (`arb-vd`) | Public domain |
| 简体中文 / 繁體中文 | 新标点和合本 / 新標點和合本 (`cmn-cu89s`, `cmn-cu89t`) | Public domain, per eBible.org |
| 한국어 | 한국어 성경 1910 (`kor`) | Public domain |
| Tagalog | Tagalog Unlocked Literal Bible (`tglulb`) | CC BY-SA 4.0: credit Door43 World Missions Community, share alike |

To regenerate, download each `https://eBible.org/Scriptures/<id>_vpl.zip`, unzip
each into a folder named after its id, and run:

```sh
node scripts/build-gospel-text.mjs <folder holding the unzipped translations>
```

Where a file's verse numbering differs from the English (the Chinese Union
Version prints a few pairs of verses as one; the French file splits two verses),
the difference is declared in the script's `QUIRKS` table and checked; any other
difference stops the build. Every language must also pass `src/i18n/locales.test.ts`:
complete titles and notes, notes that quote that language's translation exactly,
and no English left untranslated.

The section titles, notes and interface in languages other than English were
translated with AI assistance and have not yet been reviewed by native speakers.

## Hosting

GitHub Pages, deployed by `.github/workflows/deploy.yml` on every push to
`main` (tests must pass first). The custom domain is set in the repo's Pages
settings; `public/CNAME` records it but Actions-based deploys ignore the file.

DNS for yhwh.rest is on Cloudflare: `gospels` is a `CNAME` to
`yhwyorg.github.io`, and must stay **DNS only** (grey cloud). With the proxy on,
GitHub cannot issue or renew its HTTPS certificate. Verify yhwh.rest for
the yhwyorg org (`_github-pages-challenge-yhwyorg` TXT record); that is what
got certificate issuance unstuck on the previous domain.
